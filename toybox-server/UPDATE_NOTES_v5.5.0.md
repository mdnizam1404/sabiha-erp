# SABIHA ERP — Release 5.5.0 (Premium look)

## Create-account page
* The big gap between **Company ID** and **Full Name** is gone: the company name now shows on the label line
  (“✓ Your Company”) and never pushes the next field down. All fields are spaced evenly.
* The sign-in / create-account / register-company panel now **scrolls up and down** on any screen height
  (the tabs stay fixed at the top), including small laptops.

## New visual design — everywhere
* **Fonts built in** (Inter + Poppins): the app looks the same on every computer and **works fully offline**
  (no internet font download any more).
* **Sign-in screen:** animated gradient background with floating light orbs, glass card, floating logo, sliding tabs.
* **Menu:** deep gradient sidebar with glowing active marker, coloured glossy icons, smooth hover motion.
* **Top bar:** frosted-glass bar that gains a soft shadow on scroll; animated notification dot; refined user chip.
* **Pages:** animated gradient headers, glass stat cards with hover lift and light sweep, **numbers count up**,
  rounded tables with sticky headers, row highlight and gentle entrance, gradient pill tabs, soft badges with status dots.
* **Forms & pop-ups:** blurred backdrop, spring-in modals, glowing focus rings, gradient buttons with ripple.
* **Charts:** rounded bars, smooth lines, dark tooltips, animated drawing.
* **Dark mode** redesigned to match.
* **Plan & Billing / plan pop-ups / Returns** screens use the same style.
* **Platform owner console:** matching premium header, tabs, cards and bar charts.
* **Mobile app** (Android / iPhone): gradient header, floating glass tab bar, bottom-sheet pickers, soft shadows.
* **Desktop app** connect screen redesigned.
* Everything respects the computer's “reduce motion” setting.
