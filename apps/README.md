# SABIHA ERP apps
* `desktop/` — Windows + macOS app for office users (Electron). `npm install && npm start` to try it.
* `mobile/`  — Android + iOS app for salespeople (Capacitor). The `www/` folder also opens in a browser.
Installers: see **BUILD_APPS_STEP_BY_STEP.md** (beginner steps) and BUILD_APPS.md. Server hosting: see `../toybox-server/HOSTING_VPS.md`.
Both apps ask for your server address (for example `https://erp.yourcompany.com`) the first time.
